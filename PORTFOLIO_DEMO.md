# Portfolio Demo Build

This folder is a sanitized demonstration copy created from an internal application.

- Demo brand: **Demo Learning Center**
- Database: **esol2**
- Original database name was not retained in the public copy.
- All student identities, contact information, staff usernames, messages, source filenames, and institutional branding were replaced with synthetic/demo values.
- Original SQL/SQLite/database files and Git history were intentionally excluded from this copy.

## Demo login

All copied users receive the same demo password:

`demo123`

Admin usernames are generated as `admin01`, `admin02`, etc. Staff/viewer usernames are generated as `demo_userXX`.

## Important

Before publishing, run one final manual review for names, phone numbers, email addresses, internal URLs, credentials, and institution-specific text.
